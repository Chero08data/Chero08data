## 📂 Proyectos destacados (resumen de notebooks y experimentos que proporcionaste)

1. **Concrete Compressive Strength — Regression**  
   **Qué hace:** Pipeline de regresión para predecir la resistencia a compresión del concreto. Incluye EDA, ingeniería de variables, entrenamiento y evaluación con regresores clásicos (scikit-learn). Visualizaciones y métricas (RMSE/MAE) para comparar modelos y validar el flujo reproducible.

2. **Energy Efficiency — Regression**  
   **Qué hace:** Modelo predictivo para consumo energético de edificios (cargas de calefacción/enfriamiento). Contiene EDA, preprocesamiento (escalado/codificación) y comparación de modelos — desde regresores clásicos hasta enfoques neuronales (TensorFlow / Keras detectado). Foco en métricas y diagnósticos visuales.

3. **RNN Classification — Bank dataset (modelado de clientes)**  
   **Qué hace:** Modelado secuencial aplicando arquitecturas RNN (RNN/LSTM/GRU) a un dataset bancario para tareas de clasificación (p. ej., churn o respuesta a campañas). Incluye preprocesamiento de secuencias, definición y entrenamiento de modelos y métricas de clasificación.

4. **YOLO / CV para Ganadería**  
   **Qué hace:** Proyecto de visión por computador aplicando YOLO (Ultralytics / PyTorch) para detección en contextos agrícolas/ganaderos. El notebook muestra preparación de datos, manejo de anotaciones, entrenamiento e inferencia del modelo, y preprocesamiento/visualización con OpenCV.
